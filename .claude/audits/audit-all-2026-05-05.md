## Executive summary

171 findings across 14 audits — **3 blocker / 32 major / 77 minor / 59 suggestion** (1.7% blocker rate; rubric §4 respected). Biggest skill clusters: `audit-security` (28), `audit-state-and-recovery` (23). Ship-blockers are narrow and concrete:

1. `scripts/install.sh:90` declares a bash array but README and the script's own docstring instruct users `curl … | sh`. On Debian/Ubuntu (where `/bin/sh` is dash), the script syntax-errors before any download. **One-character doc fix.**
2. `internal/download/download.go:79` (`Download/fetchToFile/canSkipDownload`) has zero tests; this function writes binaries that subsequently land under sudo. Pairs with the `sec:21dc1103` O_NOFOLLOW gap on the same path.
3. `internal/runlock/runlock.go:40` symlink-refusal guard (`Lstat` reject `ModeSymlink` → `O_NOFOLLOW`) has no test. Easy fixture-based add.

The single highest-leverage **theme** spans three audits: **`ReRunSafe` is declarative-only.** `BuildSteps` panics on `ReRunSafeUnset` (recent commit `1e505e9` hardened *declaration*-time enforcement) but `Orchestrator.executeStep` never branches on the field at *runtime*. A `ReRunSafeNo` step on partial-fail-and-resume re-executes identically to a `ReRunSafeYes` step. Cross-references: `api:4f69fc9d:rerunsafe-declarative-only` (major), `state:4f69fc9d:rerunsafe-not-enforced` (major), `doc:8f46b665:phases-stepdef-missing-fields` (major). Fix is either runtime enforcement (skip `ReRunSafeNo` on rerun unless `AlreadyDone` fires — requires writing `AlreadyDone` for ~6 setup steps) or honest demotion (drop the panic; document as roadmap-deferred).
